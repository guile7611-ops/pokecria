# Manifesto de assets

Este pacote não contém sprites oficiais de Pokémon.

Ele contém:
- estrutura de pastas
- JSON de dados
- placeholders próprios em pixel art
- fontes legais pesquisadas para você baixar assets abertos ou livres

## Onde colocar sprites

Criaturas de frente:
client/src/assets/sprites/creatures/front

Criaturas de costas:
client/src/assets/sprites/creatures/back

Ícones de menu:
client/src/assets/sprites/creatures/icons

## Padrão recomendado

Front:
64x64 PNG transparente

Back:
64x64 PNG transparente

Icon:
24x24 PNG transparente

## Nomes de arquivo

Use nomes simples, sem espaço e sem acento.

Exemplo:
leafcub_front.png
leafcub_back.png
leafcub_icon.png

## Fontes legais pesquisadas

1. Tuxemon Set 1
- 154 monstros completos
- frente 64x64
- costas 64x64
- dois ícones 24x24
- ótimo para estudar o padrão de batalha

2. 50+ Monsters Pack 2D
- 56 monstros
- frente e costas
- licença CC0

3. Tiny Creatures
- mais de 100 monstros
- mais de 50 animais
- licença CC0
- inclui mapa de exemplo no Tiled

4. Guardian Monsters Artwork
- sprites de monstros, tileset e estilo RPG clássico
- verificar licença e atribuição antes de usar

5. Itch.io CC0 Monsters
- vários packs de monstros em pixel art
- sempre conferir a licença de cada pacote antes de usar

6. OpenGameArt CC0 resources
- coleção boa para tiles, monstros, inimigos, UI e efeitos

## Regra prática

Para estudo local:
- placeholders servem bem
- assets CC0 são os mais tranquilos

Para publicar um dia:
- evite qualquer sprite, nome, música ou marca oficial
- use CC0, CC-BY ou arte própria
- salve créditos em CREDITS.md quando a licença pedir
